CPU Scheduling Simulator

FCFS · SJF (non-preemptive) · SRTF (preemptive) · Round Robin. One CPU, one CPU burst per process, no I/O, zero-cost context switches. This simulator models scheduling policies; it does not reproduce Ubuntu's actual scheduler.

IDs must be unique (case-insensitive). Arrival times are whole numbers ≥ 0; CPU bursts are whole numbers ≥ 1. Ties are broken by earlier arrival, then by earlier row in this table. Enter in the last CPU burst adds a row.

Each block is one interval [start, end). Grey hatched blocks are CPU idle time. In round robin, every quantum slice is its own block (#n = slice number of that process), so consecutive slices stay visible.

Per-process metrics

Turnaround = Completion − Arrival · Waiting = Turnaround − CPU burst · Response = First start − Arrival. Averages are shown rounded and as exact fractions.
